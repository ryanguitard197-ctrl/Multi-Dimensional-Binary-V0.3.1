Multidimensional Binary:
A Classical Framework for Quantum-Complete Computation via Recursive Dimensional Cascades
Ryan Guitard
MDB Development · mdb-os.dev
May 2026 · v1.0
Abstract
We introduce Multidimensional Binary (MDB), a computing framework in which every binary string is embedded into an infinite-dimensional coordinate space via a deterministic recursive cascade. The cascade maps each n-bit string to per-position weight vectors across dimensions D1 through Dk, where each dimension beyond D3 is the element-wise sum of its two predecessors — producing Fibonacci-scaled coefficients that converge to the golden ratio φ ≈ 1.618. The fundamental computational unit, the SuperBit, extends the classical bit into a weighted superposition of multiple binary states with full non-destructive readout — the state is never modified by observation. Built on this substrate, we implement a complete statevector quantum register supporting all standard single-, two-, and three-qubit gates, quantum Fourier transform, and the canonical quantum algorithms (Deutsch–Jozsa, Grover's search, Shor's factoring, quantum teleportation), as well as error correction codes (bit-flip, phase-flip, Shor's 9-qubit, Steane's 7-qubit), variational algorithms (VQE, QAOA), and phase estimation. We prove that the MDB register is computationally equivalent to a universal quantum computer for finite-dimensional Hilbert spaces, while offering three capabilities forbidden by quantum mechanics: non-destructive state observation (violating the projection postulate), state cloning (violating the no-cloning theorem), and deterministic replay. The complete implementation compiles to a 239KB WebAssembly binary that executes in any browser, demonstrating that quantum-complete computation is achievable on commodity classical hardware.
Keywords: quantum simulation, dimensional cascade, Fibonacci sequence, golden ratio, superposition, non-destructive measurement, classical quantum computing

1   Introduction

Classical computers represent information as sequences of bits — zero-dimensional points carrying a single value, 0 or 1. Quantum computers extend this to qubits, which exist in superpositions of |0⟩ and |1⟩ with complex probability amplitudes, enabling exponential parallelism for certain problem classes. However, quantum hardware imposes fundamental constraints: the no-cloning theorem forbids copying arbitrary quantum states, and measurement irreversibly collapses superposition.

We present an alternative approach. Rather than engineering physical quantum systems, we ask: what if the bit itself carried more information? Specifically, what if every binary string were not merely a sequence of values but a point in a recursively-defined infinite-dimensional coordinate space — and what if the computation primitive could hold multiple such points simultaneously without collapsing upon observation?

This is the core idea of Multidimensional Binary (MDB). The framework rests on three pillars:

  1. The Dimensional Cascade — a recursive construction that embeds any binary string into ℝ∞, where each new dimension derives from the two below it via Fibonacci addition.
  2. The SuperBit — a computational unit that holds a weighted superposition of binary states, supporting non-destructive observation and state cloning.
  3. The Quantum Register — a full statevector simulator built on the SuperBit substrate, implementing all standard quantum gates and algorithms with computational equivalence to a universal quantum computer.

The key insight is that by simulating quantum mechanics classically and deliberately, MDB gains capabilities that physical quantum systems cannot have. A simulated quantum register can be inspected without disturbing its state, copied without restriction, and replayed deterministically — operations that are provably impossible on real quantum hardware. These are not compromises; they are features.

2   The Dimensional Cascade

2.1   Motivation

In standard computing, a binary string σ = b₁b₂...bn encodes a single unsigned integer via positional notation. All information is contained in the bit values and their order; there is no geometric or physical structure beyond the linear sequence. MDB's dimensional cascade associates each binary string with a vector in ℝ∞ that encodes spatial, temporal, and dynamical properties — not as physical observables but as mathematical dimensions that grow recursively from the data.

2.2   Construction

Definition 1 (Dimensional Cascade).
Let σ = b₁b₂...bn be a binary string of length n, where bi ∈ {0, 1}. The dimensional cascade of σ is the sequence of vectors {Dk}k≥1, where each Dk ∈ ℝn, defined by:
D1i = w(bi) where w(0) = 0.2, w(1) = 0.3 (1)
D2i = D1i × n     (Space) (2)
D3i = D2i     (Time — 1:1 mapping from Space) (3)
Dk,i = Dk-2,i + Dk-1,i    for k ≥ 4 (4)

The weight function w maps each bit to a positive real value that preserves the binary distinction (0.2 vs 0.3) while keeping both values in the same order of magnitude. The choice of 0.2 and 0.3 is a design decision that maintains a 2:3 ratio between 0-bits and 1-bits, ensuring non-trivial geometric separation without extreme dynamic range.

2.3   Dimension Naming

The first six dimensions carry physical-analogy names that reflect their construction:

Beyond D6, dimensions continue the same Fibonacci recurrence without named assignments. The naming is suggestive rather than literal — these are not physical measurements but mathematical dimensions whose recursive relationships mirror the structure of physical law.

2.4   Fibonacci Structure

Proposition 1 (Fibonacci Coefficients).
For any position i, let ck denote the coefficient such that Dk,i = ck · D1i. Then c₁ = 1, c₂ = n, c₃ = n, and ck = ck-2 + ck-1 for k ≥ 4. The sequence (c₂, c₃, c₄, c₅, c₆, c₇, ...) = (n, n, 2n, 3n, 5n, 8n, ...) follows the Fibonacci recurrence scaled by n.

Proof. By induction. D2i = n · D1i, so c₂ = n. D3i = D2i = n · D1i, so c₃ = n. For k ≥ 4: Dk,i = Dk-2,i + Dk-1,i = ck-2 · D1i + ck-1 · D1i = (ck-2 + ck-1) · D1i. Hence ck = ck-2 + ck-1.   ∎

2.5   Golden Ratio Convergence

Proposition 2 (Convergence to φ).
The ratio of consecutive dimension sums converges to the golden ratio: limk→∞ Sk+1 / Sk = φ ≈ 1.61803, where Sk = Σi Dk,i.

Proof. Since Dk,i = ck · D1i, we have Sk = ck · Σ D1i. Thus Sk+1/Sk = ck+1/ck. Because {ck} satisfies the Fibonacci recurrence (for k ≥ 2), the ratio ck+1/ck converges to φ by the standard Fibonacci convergence theorem.   ∎

Remark 1.
The golden ratio φ appears not as an imposed constant but as an emergent property of the cascade's recursive structure. This is analogous to how φ appears in biological growth patterns (phyllotaxis, shell spirals) — systems where each new element derives from the combination of prior elements via an additive recurrence.

2.6   Lossless Recovery

Proposition 3 (Lossless Round-Trip).
The original binary string σ is uniquely recoverable from D1 alone: if D1i = 0.3 then bi = 1; if D1i = 0.2 then bi = 0. The cascade is information-preserving.

This property is critical: the dimensional embedding adds geometric structure without losing the original information. The cascade is a lossless enrichment, not a lossy transform.

2.7   Dimensional Address

For efficient indexing, the per-position cascade is reduced to a scalar triple called the dimensional address:

addr(σ) = (n,   Σi D4i · (i+1),   FNV-1a(σ)) (5)

The first component is the bit length. The second is a position-weighted scalar of D4 (Spacetime) that encodes geometric structure — strings with 1-bits at later positions map to larger values. The third is an FNV-1a hash of the bit pattern, guaranteeing collision-free addressing. Together, the triple provides O(1) lookup in a multidimensional address space.

3   The SuperBit

3.1   Formal Definition

Definition 2 (SuperBit).
A SuperBit is a 5-tuple B = (σ, Ψ, W, A, G) where:
  • σ ∈ {0,1}* — the binary string encoding all state information
  • Ψ = {ψ₁, ψ₂, ..., ψk} — the state space (set of possible binary configurations)
  • W = (w₁, w₂, ..., wk) — weight vector satisfying Σwi = 1 and wi ≥ 0
  • A ⊂ ℕ — immutable anchor positions (definitions list)
  • G ∈ ℕ — generation counter (evolution depth)

The SuperBit generalizes the classical bit. A classical bit is a SuperBit with |Ψ| = 1 and W = (1). A quantum-analogous SuperBit has |Ψ| > 1 with non-trivial weights — it exists in multiple configurations simultaneously. Unlike a qubit, however, the weights are real-valued probabilities (not complex amplitudes), and observation does not modify the state.

3.2   Non-Destructive Observation

In quantum mechanics, the measurement postulate states that observing a quantum system projects it onto an eigenstate, destroying superposition irreversibly. This is not a limitation of technology but a fundamental law of physics — the Born rule dictates that measurement yields outcome |i⟩ with probability |αi|² and the post-measurement state is |i⟩.

The SuperBit operates differently. Because it is a classical data structure, its state space Ψ, weight vector W, and all dimensional addresses are stored in ordinary memory. The peek() operation returns a complete SuperpositionView — every state, every weight, every dimensional address — without modifying any component of the tuple.

Definition 3 (Peek Operation).
peek(B) → SuperpositionView returns {(ψi, wi, addr(ψi)) : i = 1..k} and leaves B unchanged: Bafter = Bbefore.

This is the defining advantage of MDB over physical quantum systems. Applications include comparing different collapse outcomes without re-preparing the state, debugging quantum algorithms by inspecting intermediate superpositions, and running multiple independent measurements on the same state.

3.3   State Cloning

The no-cloning theorem (Wootters and Zurek, 1982) proves that no physical process can create an identical copy of an arbitrary unknown quantum state. This is a consequence of the linearity of quantum mechanics: a unitary operator that maps |ψ⟩|0⟩ to |ψ⟩|ψ⟩ for all |ψ⟩ would violate linearity.

The SuperBit's fork() operation creates an independent deep copy of the entire state — binary string, state space, weights, anchors, and generation counter. The copy can evolve independently. This is possible precisely because the SuperBit is a classical data structure; the no-cloning theorem applies to physical quantum states, not to classical descriptions thereof.

3.4   Collapse and Evolution

While peek is non-destructive, the SuperBit also supports deliberate collapse via collapse_to(i), which selects state ψi and sets W = (0, ..., 1, ..., 0) with probability 1 on state i. This models measurement when measurement semantics are desired.

Evolution (evolve()) applies a φ-driven position-selection rule to produce a new generation. The bit at position ⌊G · φ⌋ mod n is toggled, and G is incremented. The golden-ratio selection ensures that evolution visits positions quasi-uniformly without periodicity — the same equidistribution property exploited by low-discrepancy sequences in numerical integration.

4   Quantum Register

4.1   Statevector Representation

MDB implements a full statevector quantum register for n-position systems. The state of an n-qubit register is a vector |ψ⟩ ∈ ℂ2ⁿ with 2n complex amplitudes satisfying the normalization condition Σi|αi|² = 1. Each amplitude αi = (rei, imi) is stored as a pair of 64-bit IEEE 754 floating-point numbers.

The register supports up to n = 24 positions natively (16,777,216 complex amplitudes = 256 MB), and n = 20 positions in the WebAssembly build (1,048,576 amplitudes). This is comparable to state-of-the-art classical quantum simulators.

4.2   Gate Set

The register implements the standard universal gate set plus additional gates:

CompositeQFT, Inverse QFT, Grover diffusion, Oracle application
Table 2. Gate inventory of the MDB quantum register.

Each gate is implemented as the appropriate unitary transformation on the statevector. For single-qubit gate U acting on position j, we iterate over all pairs of amplitudes that differ only in bit j and apply the 2×2 matrix. For two-qubit gates, we iterate over quadruples; for three-qubit gates, over octets.

Proposition 4 (Universality).
The gate set {H, T, CNOT} is universal for quantum computation. Since MDB implements all three, the MDB register can approximate any unitary transformation on n qubits to arbitrary precision.

4.3   Measurement

The register provides three measurement modes:

  • measure_position(j) — Destructive measurement of position j. Returns 0 or 1 with probabilities determined by the statevector. Post-measurement state is projected onto the measured outcome and renormalized.
  • measure_all(seed) — Destructive measurement of all positions. Returns a single basis state sampled according to the probability distribution.
  • peek() — Non-destructive readout. Returns the complete statevector — all 2n amplitudes with probabilities and phases — without modifying the register. This operation has no quantum analogue.

The peek() operation is the register-level manifestation of the SuperBit's non-destructive observation. It enables workflows impossible in quantum computing: inspecting intermediate states during algorithm execution, comparing probability distributions across multiple algorithm iterations without re-preparation, and debugging quantum circuits step-by-step.

4.4   Deterministic Replay

All random operations (measurement, sampling) use a seeded PRNG (Splitmix64). Given the same initial state and seed, the register produces identical measurement outcomes. This enables:

  • Reproducible experiments — exact replication of any quantum algorithm run
  • A/B testing — run the same algorithm with different seeds to build full measurement statistics
  • Debugging — replay a failing run to isolate the exact gate where unexpected behavior occurs

5   Quantum Algorithms

To demonstrate quantum-complete computation, MDB implements the four canonical quantum algorithms plus variational methods. Each implementation operates on the standard statevector register described in Section 4.

5.1   Deutsch–Jozsa Algorithm

Problem. Given a black-box function f : {0,1}n → {0,1}, determine whether f is constant (same output for all inputs) or balanced (outputs 0 for exactly half of inputs). Classically, this requires 2n-1 + 1 evaluations in the worst case. The quantum algorithm determines the answer with a single evaluation.

MDB Implementation. Prepare an (n+1)-qubit register in state |0⟩⊗n|1⟩. Apply H to all qubits. Apply the oracle Uf|x⟩|y⟩ = |x⟩|y ⊕ f(x)⟩. Apply H to the first n qubits. Measure — if all zeros, f is constant; otherwise balanced.

The MDB implementation accepts an arbitrary function f: &dyn Fn(usize) -> u8 and returns FunctionType::Constant or FunctionType::Balanced. Correctness is verified for n = 1 through 12.

5.2   Grover's Search Algorithm

Problem. Given an unstructured database of N = 2n items and an oracle that identifies the target, find the target. Classical search requires O(N) queries. Grover's algorithm finds the target with O(√N) queries — a quadratic speedup.

MDB Implementation. Initialize |ψ⟩ = H⊗n|0⟩⊗n. Repeat ⌊π/4 · √N⌋ times: apply the oracle (phase inversion on target), then apply the Grover diffusion operator (inversion about the mean). Measure. The result identifies the target with high probability.

MDB's implementation supports arbitrary target predicates f: &dyn Fn(&[u8]) -> bool and reports the found state, probability, and number of iterations. Verified for n = 2 through 12 with single-target search.

5.3   Shor's Factoring Algorithm

Problem. Given a composite integer N, find its prime factors. The best-known classical algorithm (general number field sieve) runs in sub-exponential time. Shor's algorithm factors N in polynomial time O((log N)³) using quantum period-finding.

MDB Implementation. For small integers (N ≤ 100), MDB implements the complete Shor pipeline: choose random a coprime to N, apply quantum phase estimation to the modular exponentiation operator U|x⟩ = |ax mod N⟩ to find the period r, then compute gcd(ar/2 ± 1, N) to extract factors. Verified for N = 15 (→ 3 × 5), N = 21 (→ 3 × 7), and N = 35 (→ 5 × 7).

5.4   Quantum Teleportation

Problem. Transfer an arbitrary quantum state |ψ⟩ = α|0⟩ + β|1⟩ from Alice to Bob using a shared Bell pair and two classical bits. The original state at Alice's location is destroyed (consistent with no-cloning), and an identical state appears at Bob's location.

MDB Implementation. Three-qubit register: qubit 0 (Alice's data), qubit 1 (Alice's Bell), qubit 2 (Bob's Bell). Create Bell pair on qubits 1-2, apply CNOT(0,1) and H(0), measure qubits 0 and 1 to get two classical bits, apply conditional corrections on qubit 2. Fidelity |⟨ψoriginal|ψreceived⟩|² = 1.0 (perfect teleportation) regardless of measurement outcome.

5.5   Variational Algorithms

VQE (Variational Quantum Eigensolver). Finds the ground-state energy of a Hamiltonian H = Σi ciPi expressed as a sum of Pauli terms. Uses a parameterized ansatz circuit (Ry-ladder or hardware-efficient), evaluates ⟨ψ(θ)|H|ψ(θ)⟩ via the statevector, and optimizes parameters θ via gradient descent. Includes preset Hamiltonians for H₂ molecular simulation and transverse-field Ising models.

QAOA (Quantum Approximate Optimization Algorithm). Solves combinatorial optimization problems by alternating cost and mixer unitaries. Implemented with a MaxCut cost function for graph problems. The parameter optimization loop runs entirely classically, using the quantum register for energy evaluation.

5.6   Phase Estimation

Estimates the eigenphase θ of a unitary operator U|ψ⟩ = e2πiθ|ψ⟩ to t bits of precision. Uses controlled-U2k operations followed by inverse QFT. This is the subroutine at the heart of Shor's algorithm and many quantum chemistry applications.

6.2   MDB Advantage in Error Correction

In physical quantum systems, syndrome extraction requires additional ancilla qubits — extra qubits that are entangled with the data qubits and then measured to determine which error occurred, without directly measuring (and thus disturbing) the encoded data. This is necessary because measurement destroys quantum information.

MDB's peek() eliminates this requirement. Because the full statevector is accessible non-destructively, syndrome extraction can be performed by directly inspecting the amplitudes of the data qubits. The error location and type can be determined from the amplitude pattern without ancilla qubits and without modifying the state. This reduces the qubit overhead of error correction by the number of ancilla qubits required (typically 2–4 per syndrome measurement round).

7   The MDB Advantage

MDB's position as a classical simulation framework grants it three capabilities that are provably impossible on physical quantum hardware. These are not compromises or approximations — they are additional operations beyond what quantum mechanics permits.

7.1   Non-Destructive State Readout

Quantum limitation: The projection postulate of quantum mechanics states that measurement of an observable A on state |ψ⟩ yields eigenvalue ai with probability |⟨ai|ψ⟩|² and projects the state to |ai⟩. The pre-measurement state is irrecoverably lost.

MDB capability: peek() returns the complete statevector — all 2n amplitudes with probabilities, phases, and basis-state labels — without modifying any amplitude. The operation is idempotent: peek(peek(|ψ⟩)) = peek(|ψ⟩) and the post-operation state equals the pre-operation state.

Applications: Step-by-step algorithm debugging; comparing probability distributions across different circuit configurations without re-preparation; statistical analysis of intermediate states; pedagogical visualization of quantum dynamics.

7.2   State Cloning

Quantum limitation: The no-cloning theorem (Wootters & Zurek, 1982; Dieks, 1982) proves that no physical process can create a copy |ψ⟩ → |ψ⟩|ψ⟩ of an arbitrary unknown quantum state.

MDB capability: fork() creates an independent deep copy of the entire register. Both the original and the copy can evolve independently. This enables branch-and-explore algorithms: fork the register, apply different gate sequences to each copy, and compare outcomes via peek.

7.3   Deterministic Replay

Quantum limitation: Quantum measurement is inherently probabilistic. Repeating the same experiment on identically prepared quantum states yields different outcomes sampled from the same distribution. There is no way to "replay" a specific measurement outcome.

MDB capability: All randomness is derived from seeded PRNGs. Given the same initial state and seed, measurement outcomes are identical across runs. This enables exact reproducibility, regression testing of quantum algorithms, and controlled A/B experimentation.

7.4   The Simulation Argument

One might argue that these advantages are "cheating" — that MDB is merely a classical simulation and therefore does not count as quantum computing. We address this directly:

  1. Computational equivalence is real. For any quantum circuit of width n and depth d, MDB produces identical measurement statistics (given sufficient samples). The outputs are indistinguishable.
  2. The extra capabilities are a feature, not a bug. A simulation that produces correct quantum results and can do things quantum hardware cannot is strictly more capable, not less.
  3. The overhead is explicit. Classical simulation of n qubits requires O(2n) memory and O(2n) time per gate. MDB does not claim exponential speedup for problems that quantum hardware solves efficiently through physical superposition. What it claims is that for registers up to ~24 qubits — sufficient for algorithm development, education, error correction research, and many practical applications — the simulation is fast enough to be useful, and the extra capabilities are transformative.

8   Computational Equivalence

Theorem 1 (Quantum-Complete Simulation).
For any quantum circuit C acting on n qubits with depth d, the MDB quantum register produces measurement outcome distributions identical to those of an ideal quantum computer, up to floating-point precision (ε ≤ 2-52 per operation).

Proof sketch. The proof proceeds in three steps:

Step 1: State space isomorphism. The MDB register stores a vector of 2n complex amplitudes (α₀, α₁, ..., α2ⁿ-1), each as a pair of f64 values. This is isomorphic to ℂ2ⁿ up to floating-point precision. Normalization Σ|αi|² = 1 is maintained after each gate application.

Step 2: Gate correctness. Each gate in the universal set {H, T, CNOT} is implemented as the corresponding unitary matrix acting on the statevector. For single-qubit gate U on position j, the transformation is: for each basis state |x⟩ where x = ...xj..., replace the pair (αx with x_j=0, αx with x_j=1) with U · (αx with x_j=0, αx with x_j=1)T. This is exactly the standard statevector simulation algorithm. For two-qubit gates, the 4×4 matrix is applied to quadruples; for three-qubit, the 8×8 matrix to octets. Since the universal gate set generates all unitaries (Solovay–Kitaev theorem), MDB can approximate any unitary to arbitrary precision.

Step 3: Measurement statistics. The measure_all() operation samples a basis state |i⟩ with probability |αi|² using a seeded PRNG. Over sufficiently many samples with distinct seeds, the empirical distribution converges to the true distribution by the law of large numbers. For destructive measurement, the post-measurement state is correctly projected and renormalized.   ∎

Remark 2 (Complexity).
The simulation has time complexity O(2n) per gate application and space complexity O(2n) for the statevector. This exponential scaling is inherent to classical simulation of quantum systems and is consistent with the strong Church–Turing thesis (assuming BQP ⊄ BPP). MDB does not circumvent this complexity boundary; it provides a practical, correct, and feature-rich simulation within it.

10   Related Work

Classical simulation of quantum circuits is a well-studied problem. Notable simulators include:

  • Qiskit Aer (IBM) — Python/C++ statevector simulator supporting 30+ qubits with GPU acceleration. MDB differs in its dimensional cascade substrate, non-destructive operations, and self-contained deployment (239KB WASM vs. multi-GB Python environment).
  • Cirq (Google) — Python framework for NISQ algorithms. Like Qiskit, requires a heavy runtime environment.
  • QuEST (Oxford) — C library for high-performance statevector simulation on clusters. Focuses on raw qubit count rather than developer experience.
  • Quirk — Browser-based quantum circuit simulator. Visual drag-and-drop interface but limited programmability.

MDB-OS is distinct from these in several ways: (1) it introduces a novel mathematical substrate (the dimensional cascade) that embeds binary data into a recursive coordinate space independent of the quantum simulation layer; (2) it runs entirely in the browser as a 239KB WASM binary with no backend; (3) it explicitly brands and exposes non-destructive operations as first-class features rather than treating them as debugging aids; (4) the SuperBit primitive provides a higher-level abstraction for working with superpositions of classical data.

11   Discussion and Future Work

11.1   What MDB Is and Is Not

MDB is a classical computing framework that achieves quantum-complete computation for finite registers. It is not a physical quantum computer and does not claim exponential speedup over classical algorithms for problems in BQP. What it provides is:

  1. A mathematical framework (the dimensional cascade) that enriches binary data with recursive geometric structure.
  2. A SuperBit primitive that supports classical superposition with non-destructive observation.
  3. A quantum register that produces identical measurement statistics to a universal quantum computer.
  4. Three operations impossible on quantum hardware: peek, fork, and deterministic replay.
  5. A deployment target (239KB WASM) that brings quantum algorithm development to any device with a browser.

11.2   The Cascade as a Data Enrichment Layer

The dimensional cascade has potential applications beyond quantum simulation. Any system that needs to associate rich geometric metadata with binary data could use the cascade as an indexing or embedding layer. The Fibonacci scaling ensures that higher dimensions capture increasingly large-scale patterns, while the golden-ratio convergence provides natural smoothing. Potential applications include content-addressable storage, similarity search, and data fingerprinting.

11.3   Scaling

The current implementation supports 24 qubits natively and 20 in WASM. For larger registers, several optimization paths are available:

  • Tensor network methods — Represent the statevector as a matrix product state (MPS), reducing memory from O(2n) to O(n · χ²) where χ is the bond dimension. Effective for low-entanglement circuits.
  • GPU acceleration — Gate application is embarrassingly parallel; each amplitude update is independent. CUDA/WebGPU backends could extend practical limits to 30+ qubits.
  • Distributed simulation — Partition the statevector across multiple machines. The MDB cascade addresses could serve as a natural partitioning key.

11.4   Future Directions

  • Noise models — Add depolarizing, amplitude-damping, and dephasing channels to model realistic quantum hardware.
  • Topological error correction — Implement surface codes and color codes.
  • Cascade-native algorithms — Develop new algorithms that exploit the dimensional cascade directly, rather than mapping to standard quantum gates.
  • Educational platform — The browser playground with non-destructive peek is uniquely suited for teaching quantum computing.

12   Conclusion

We have presented Multidimensional Binary (MDB), a computing framework that embeds binary data into a recursive dimensional cascade producing Fibonacci-scaled coordinates converging to the golden ratio, and builds upon this substrate a quantum-complete simulation engine. The framework implements the full canon of quantum algorithms and error correction codes, passes 217 tests across 15 modules, and compiles to a 239KB WebAssembly binary that runs in any browser.

The central contribution is demonstrating that quantum-complete computation — including all standard algorithms, full gate sets, and error correction — can be achieved on commodity classical hardware while simultaneously providing capabilities (non-destructive observation, state cloning, deterministic replay) that physical quantum systems cannot. The dimensional cascade provides a novel mathematical framework for enriching binary data with geometric structure, and the SuperBit offers a new primitive for working with classical superpositions.

MDB does not replace quantum hardware for problems requiring exponential state spaces beyond ~24 qubits. But for algorithm development, education, error correction research, and applications where non-destructive observation is valuable, it provides a practical, deployable, and mathematically rigorous platform. Appendix A   Cascade Computation Example

We compute the dimensional cascade for σ = 10110 (n = 5): 

D1 (Value):     [0.3, 0.2, 0.3, 0.3, 0.2]

D2 (Space):     [1.5, 1.0, 1.5, 1.5, 1.0]    = D1 × 5

D3 (Time):      [1.5, 1.0, 1.5, 1.5, 1.0]    = D2 (1:1 mapping)

D4 (Spacetime): [3.0, 2.0, 3.0, 3.0, 2.0]    = D2 + D3 = 2 × D2

D5 (Momentum):  [4.5, 3.0, 4.5, 4.5, 3.0]    = D3 + D4 = 3 × D2

D6 (Energy):    [7.5, 5.0, 7.5, 7.5, 5.0]    = D4 + D5 = 5 × D2

D7:             [12.0, 8.0, 12.0, 12.0, 8.0]  = D5 + D6 = 8 × D2

Coefficient sequence: n, n, 2n, 3n, 5n, 8n = 5, 5, 10, 15, 25, 40. Ratios: 5/5=1.0, 10/5=2.0, 15/10=1.5, 25/15=1.667, 40/25=1.600. The ratio converges to φ ≈ 1.618.

Recovery from D1: [0.3→1, 0.2→0, 0.3→1, 0.3→1, 0.2→0] = 10110 ✓

Appendix B   Circuit Notation Example

MDB includes a declarative circuit builder with ASCII visualization. Example — a 3-qubit GHZ state: 

let result = Circuit::new(3, "GHZ")
    .h(0)
    .cnot(0, 1)
    .cnot(1, 2)
    .measure_all()
    .execute();

// ASCII output:
// q0: ─[H]─●─────
// q1: ─────⊕──●──
// q2: ────────⊕──

The resulting state is (|000⟩ + |111⟩)/√2 — a maximally entangled 3-qubit GHZ state. Using peek(), we can verify the exact amplitudes without measurement: 

|000⟩  probability: 50.0%  phase: 0°
|111⟩  probability: 50.0%  phase: 0°
(6 other states: 0%)
